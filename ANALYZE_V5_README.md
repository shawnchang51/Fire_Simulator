# V5 Data Analyzer and Validator

Comprehensive analysis and validation tool for hierarchical training data generated by `generate_training_data_v5.py`.

## Features

### Data Validation
- ✓ Hierarchical structure integrity (Plans → Exits → Doors)
- ✓ Pair type distribution (same-exit, cross-exit, cross-plan)
- ✓ Label consistency and balance
- ✓ Required field validation
- ✓ Data quality checks (duplicates, missing values)
- ✓ Train/val/test split ratios

### Statistical Analysis
- **Hierarchical Structure**
  - Exit configs per plan (mean, min, max, distribution)
  - Door configs per exit (mean, min, max, distribution)
  - Variance analysis across hierarchy levels

- **Pair Distribution**
  - Counts and ratios by pair type
  - Label balance (positive/negative)
  - Score difference distributions
  - Expected vs actual ratio validation

- **Performance Metrics**
  - Survival rate statistics (mean, std, min, max, median)
  - Score statistics and variance
  - Evacuation time distributions
  - Fire damage analysis

### Visualizations
- Pair type distribution bar chart
- Score difference box plots by pair type
- Hierarchical structure histograms
- Performance metric distributions

## Usage

### Basic Analysis

```bash
# Run analysis and print report
python analyze_v5_data.py --data-dir ./training_data_v5
```

### Save Report to File

```bash
# Save detailed JSON report
python analyze_v5_data.py --data-dir ./training_data_v5 \
  --save-report analysis_report.json
```

### Generate Visualizations

```bash
# Generate plots (requires matplotlib)
python analyze_v5_data.py --data-dir ./training_data_v5 --plot

# Specify custom plot directory
python analyze_v5_data.py --data-dir ./training_data_v5 \
  --plot --plot-dir ./my_analysis_plots
```

### Complete Analysis

```bash
# Full analysis with report and plots
python analyze_v5_data.py --data-dir ./training_data_v5 \
  --save-report full_report.json \
  --plot
```

## Validation Issues

The analyzer categorizes issues by severity:

### Errors (Critical)
- Missing required fields in pairs
- Label-score inconsistencies
- Missing `exit_config_id` in results
- Structural data corruption

**Action**: Fix immediately before training

### Warnings (Important)
- Ratio deviations (> 10% from expected)
- Imbalanced labels (> 10% from 50/50)
- Low score variance (< 0.01)
- Low survival rates (< 30% avg)
- Duplicate entries

**Action**: Review and consider regenerating data

### Info (Informational)
- Minor deviations
- Usage statistics

**Action**: No action required

## Integration with Training Pipeline

```python
# Example: Validate before training
import subprocess
import sys

result = subprocess.run([
    'python', 'analyze_v5_data.py',
    '--data-dir', './training_data_v5',
    '--save-report', 'validation.json'
], capture_output=True)

if result.returncode != 0:
    print("Dataset validation failed!")
    sys.exit(1)

# Proceed with training
print("Dataset validated successfully!")
# ... start training ...
```

## Advanced Usage

### Programmatic Access

```python
from analyze_v5_data import V5DataAnalyzer

# Create analyzer
analyzer = V5DataAnalyzer('./training_data_v5')

# Load data
analyzer.load_data()

# Run analysis
report = analyzer.analyze()

# Access results programmatically
print(f"Total pairs: {report.total_pairs:,}")
print(f"Validation errors: {len(report.get_errors())}")

# Check specific statistics
same_exit_ratio = report.pair_stats['type_distribution'].get('same', 0)
print(f"Same-exit ratio: {same_exit_ratio:.2%}")

# Generate visualizations
analyzer.plot_distributions('./custom_plots')

# Save report
analyzer.save_report('report.json')
```

### Filtering Specific Issues

```python
# Get only errors
errors = report.get_errors()
for error in errors:
    print(f"[{error.category}] {error.message}")

# Get warnings about distribution
dist_warnings = [
    w for w in report.get_warnings()
    if w.category == 'distribution'
]
```

## Tips

1. **Always validate after generation**: Run analyzer immediately after `generate_training_data_v5.py` completes

2. **Check plots**: Visual inspection often reveals issues not caught by numerical checks

3. **Compare reports**: Save reports from different runs to track data quality over time

4. **Monitor score variance**: Too low variance means configurations are too similar (poor training signal)

5. **Verify hierarchical structure**: Ensure exit/door counts match your generation config

## Troubleshooting

### "No pairs found in dataset"
- Check that `*_pairs.jsonl` files exist
- Verify generation completed successfully

### "Missing exit_config_id"
- Dataset may be from V4 (not V5)
- Regenerate with `generate_training_data_v5.py`

### Plots not generating
- Install matplotlib: `pip install matplotlib`
- Check write permissions in output directory

### High label imbalance
- Review score margin in pair constructor
- May need to adjust score weighting formula
- Consider regenerating with different parameters
